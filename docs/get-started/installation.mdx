---
title: "Installation"
---

Merit is an open-source Python library for testing AI systems. You can install it via `uv`:

```bash
uv add appmerit
```

<Tip>
The package is installed as `appmerit`, but all imports should be from `merit` (for example, `import merit` and `from merit.predicates import ...`).
</Tip>
<Callout icon="key" color="#FFC107" iconType="regular">Merit is free and open-source, but it also includes premium features like [AI Predicates](/concepts/semantic-predicates) that require a Merit API key.</Callout>
